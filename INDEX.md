## 🎓 Key Project Facts to Remember

**What is MCP-Citadel?**
An AI-powered security vulnerability analysis system that uses Google Gemini AI to classify threats, calculate severity scores, and provide remediation guidance.

**Key Numbers:**
- 200+ vulnerabilities in dataset
- 30+ vulnerability categories
- 92% classification accuracy
- 2-5 seconds analysis time
- 0-10 CVSS severity scale
- 9-10 remediation steps per analysis

**Technology:**
- Frontend: React 19.1.1
- Backend: Flask (Python)
- AI: Google Gemini 2.0 Flash
- ML: Sentence Transformers, scikit-learn
- Database: SQLite3

**Architecture:**
Three-tier: Presentation (React) → Application (Flask) → Data (SQLite + Gemini API)
